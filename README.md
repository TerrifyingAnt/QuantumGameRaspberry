# «Суперпозиция» — онлайн-версия

<p align="center">
  <img src="front/src/assets/drawable/logo.png" alt="Логотип Суперпозиции" width="160">
</p>

Полностью **онлайн**-игра «Суперпозиция»: два (и более) клиента в браузере или на телефоне, общий сервер в сети, **цифровые карты** без NFC и без общего киоск-экрана.

Логика регистров и эффектов карт совпадает с прошивкой ESP32 ([`controller/`](controller)); runtime этой ветки — Node.js ([`server/`](server)) + React ([`front/`](front)).

## Что это за версия

| | Раньше (ESP / стол) | Эта версия |
|---|---|---|
| Клиенты | телефоны + SoftAP / один экран Pi | телефоны или браузеры в Wi‑Fi |
| Карты | физические RFID / PN532 | лента карт на экране → `playCard` |
| Старт партии | скан / автостарт стола | лобби → приглашение |
| NFC | обязателен или mock | **выключен** (`NFC_MODE=off`) |

## Быстрый старт

**Windows (разработка):**

```powershell
.\scripts\run-dev.ps1
```

Откройте два окна браузера на [http://127.0.0.1:5173](http://127.0.0.1:5173) (или телефон в той же сети на IP ПК). На главной пригласите второго игрока → оба попадут на `/game`.

**Linux / macOS / Raspberry Pi (сборка + один сервер):**

```bash
chmod +x scripts/*.sh
./scripts/run-pi.sh
# клиенты: http://<ip-хоста>:8080
```

**Docker:**

```bash
docker compose up --build
# клиенты: http://localhost:8080
```

Нужны только **Node.js 20+** и npm (или Docker). Python, PN532 и дисплей Pi **не требуются**.

## Как играть

```text
Клиент A  ←── Wi‑Fi / LAN ──→  Клиент B
                 ↑
           server :8080
     лобби · WebSocket · правила
```

1. Оба игрока открывают сайт сервера и появляются в списке на главной.
2. Один отправляет **приглашение** (число кубитов), второй принимает (колокольчик / уведомления).
3. Оба переходят на `/game`.
4. В свой ход:
   - коснитесь **кубита** (цель) → `selectTarget`;
   - нажмите **карту** в ленте внизу → `playCard`.
5. Карты без цели можно сыграть сразу: `identity`, `barrier`, `reshuffle`, `kronecker_multiplication`.
6. Для `swap`, `rotate_*`, `quantum_lucky` сервер запросит вторую цель или грань.
7. Обычно **2 карты за ход** (исключения — [`RULES.md`](RULES.md)). Победа — ваш регистр совпал с целью.

Подробности протокола: [`EVENTS.md`](EVENTS.md). Список карт: [`cards.md`](cards.md).

## Состав репозитория

| Путь | Роль |
|---|---|
| [`server/`](server) | HTTP + WebSocket, игровая логика, приглашения |
| [`front/`](front) | Лобби, `/game`, картотека |
| [`controller/`](controller) | Эталон прошивки ESP32 (не запускается в этой версии) |
| [`scripts/run-dev.ps1`](scripts/run-dev.ps1) | Dev: сервер + Vite |
| [`scripts/run-pi.sh`](scripts/run-pi.sh) | Сборка фронта и `npm start` |
| [`docker-compose.yml`](docker-compose.yml) | Образ с онлайн-настройками по умолчанию |

## Переменные окружения

| Переменная | Default | Описание |
|---|---|---|
| `PORT` | `8080` | HTTP и WebSocket |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания |
| `TABLETOP_MODE` | `0` | `0` — лобби и телефоны (эта версия) |
| `NFC_MODE` | `off` | Карты только через `playCard` |
| `FRONT_DIST` | `front/dist` | Каталог сборки клиента |

Ручной запуск без скриптов:

```bash
cd server && NFC_MODE=off TABLETOP_MODE=0 npm install && npm run dev
# другой терминал:
cd front && npm install && npm run dev   # http://127.0.0.1:5173
```

## Телефоны в локальной сети

1. Сервер и телефоны в одной Wi‑Fi (или hotspot хоста).
2. Узнать IP: `hostname -I` (Linux) / `ipconfig` (Windows).
3. На телефоне: `http://<ip>:8080` — сокет: `ws://<ip>:8080/ws`.

В режиме Vite на ПК прокси `/ws` уже настроен в [`front/vite.config.ts`](front/vite.config.ts).

## Если что-то не работает

- **Пустая страница / 503:** соберите фронт: `cd front && npm run build`, перезапустите сервер.
- **Не видно второго игрока:** оба должны быть подключены к одному хосту; проверьте WebSocket.
- **Карта не срабатывает:** должен быть ваш ход; для карт с целью сначала выберите кубит.
- **Приглашение не приходит:** смотрите колокольчик на главной / страницу уведомлений.

## Наследие: стол и NFC (не по умолчанию)

Код `/tabletop` и моста PN532 в репозитории остаётся, но **эта версия их не использует**. Включить вручную:

```bash
TABLETOP_MODE=1 NFC_MODE=hardware ./scripts/run-pi.sh
# Docker + ридер:
# docker compose -f docker-compose.yml -f docker-compose.hardware.yml up --build
```
